# Fieldnote — completed fictional example

**Everything in this folder is illustrative:** the product, source, brand, draft, review records and learning. No real review, human approval, publication or performance measurement took place. Example URLs use `.example.invalid` and cannot be live destinations.

Read the [source register](source-register.md), [brief](campaign-brief.md), [bad draft](bad-draft.md), [corrected draft](draft.md), [review](review.md), [handoff](handoff.md) and [lesson](lesson.md) in that order.

The mistake is small: **“planned” becomes “available.”** The invented release supports shared checklists. It does not support live collaboration; pricing is unknown. The first draft sounds plausible and still fails.

The [brand folder](brand/voice-guide.md) is fully filled for this fictional exercise. To check the fixture from the repository root:

```sh
python3 hooks/check-setup.py --root data/examples/fieldnote --visual --brief campaign-brief.md
```

A passing setup check only means the required files are present and filled. It does not mean the product facts are real or the draft is approved. Use [blank templates](../../templates/README.md) for your own campaign.
