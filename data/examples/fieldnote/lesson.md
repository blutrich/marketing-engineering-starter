## The correction

- **After:** “Live collaboration is planned and is not available in this release.”

## Reusable rule

When turning release notes into copy, retain the capability's availability and scope. A source that mentions the feature does not necessarily support saying it is available. This applies to roadmap, beta, limited-rollout and released capabilities alike.

Failing example: changing “planned” to “available now” because the feature is described in the release source.
