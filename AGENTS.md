# Agent entry point

For repository maintenance, implement the requested code or documentation change directly. Brand placeholders are expected in a starter; they do not require an interview before editing this repository. Preserve unrelated edits and follow relevant tests and contribution instructions.

For brand setup, marketing content, or source digests, read [CLAUDE.md](CLAUDE.md), which holds the shared operating workflow for any AI assistant. Its role files describe prompts, not guaranteed installed agents or automatic approvals.

Keep real campaign work in ignored `data/local/<campaign>/`. Never treat the fictional Fieldnote example as evidence about a real product. The nested `feature-launch-workshop/` has its own entry point; follow it when working in that exercise.
