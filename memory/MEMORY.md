# Memory index

Shared memory holds lessons the participant explicitly selected for future work. It is not model training, an automatic feedback system, or a substitute for current evidence.

- [patterns.md](patterns.md) — selected observations, their evidence and scope, and any explicitly approved rule changes.

Start empty. Capture raw observations in `data/local/<campaign>/lesson.md` using the lesson template. Promote only with the participant's explicit choice, and remove confidential details before adding anything to this tracked file or its index. Repetition alone does not authorize promotion.

When reading memory, check whether the lesson applies to the current audience, channel, product, and date. A new source or participant instruction can supersede an old lesson. Keep the reason and reference when retiring an entry.
